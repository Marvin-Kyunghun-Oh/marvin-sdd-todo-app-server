# PRD — Marvin's Todo App (초안)

> SDD 1단계(Specify) 산출물. 근거 자료: `Marvins_Todo_APP_Wireframe.pdf` (3장).
> 상태: **초안 (사람의 승인 대기)**
> 세부 요구사항과 수용 기준은 `REQUIREMENTS.md`, 확정된 판단은 `DECISION_LOG.md`를 따른다.

## 1. 배경과 목적
- 할 일을 적고, 끝낸 것을 표시하고, 마감이 지난 것을 놓치지 않게 해 주는 간단한 할 일 앱이다.
- 이 저장소는 그 앱의 **서버**를 만든다. 서버는 화면이 필요로 하는 모든 동작(추가, 보기, 수정, 완료 표시, 삭제)을 제공한다.
- 이 프로젝트는 명세 주도 개발(SDD)과 테스트 주도 개발(TDD)을 연습하는 학습 목적도 가진다.

## 2. 사용자
- 혼자 쓰는 사람 한 명. 로그인과 계정 구분은 없다.
- 사용자는 할 일 몇 개부터 수십 개 정도를 다루는 일상적인 용도로 쓴다.

## 3. 해결하려는 문제
| 문제 | 기대하는 결과 |
| --- | --- |
| 해야 할 일을 머릿속에만 두면 잊는다 | 제목만 적어도 바로 추가할 수 있다 |
| 무엇이 남았는지 한눈에 알기 어렵다 | 남은 개수와 진행 중/완료 구분이 보인다 |
| 마감이 지난 일을 놓친다 | 마감이 지난 미완료 할 일이 구분되어 보인다 |
| 잘못 적은 내용을 고치기 어렵다 | 제목, 설명, 마감일, 완료 여부를 언제든 수정할 수 있다 |

## 4. 와이어프레임 요약
**목록 화면**
- 제목 아래에 "N개 남음"이 표시된다.
- 입력창에 제목만 적고 추가한다.
- 전체/진행 중/완료 보기 전환이 있고, 각각 개수가 붙는다.
- 각 항목에는 완료 체크, 제목, 마감일, "기한 지남" 표시, 수정·삭제 버튼이 있다.
- 완료된 항목은 취소선으로 표시된다.

**수정 화면**
- 제목(필수), 설명(선택), 마감일, 완료로 표시, 저장, 취소, 삭제가 있다.

**예외 화면**
- 할 일이 하나도 없을 때
- 제목 없이 추가했을 때
- 없는 할 일을 열었을 때

## 5. 범위

### 5.1 범위 안
- 할 일 추가 (제목 필수)
- 할 일 목록 보기 (등록한 순서)
- 진행 중/완료 구분 보기와 개수 요약
- 완료 표시와 되돌리기
- 할 일 한 건 보기
- 할 일 수정 (제목, 설명, 마감일, 완료 여부)
- 마감일 지정과 삭제
- 마감 지남 판정
- 할 일 삭제 (복구 불가)
- 빈 상태와 오류 상황의 일관된 안내

### 5.2 범위 밖
| 항목 | 비고 |
| --- | --- |
| 로그인, 여러 사용자, 공유 | 한 명이 쓴다고 가정 |
| 알림, 이메일 | 마감 임박 알림 없음 |
| 우선순위, 태그, 하위 할 일 | 와이어프레임에 없음 |
| 검색 | 와이어프레임에 없음 |
| 정렬 방식 변경 | 등록한 순서로 고정 |
| 반복 일정 | 와이어프레임에 없음 |
| 휴지통, 삭제 복구 | 삭제하면 복구 불가 |
| 페이지 나눔 | 목록 전체를 한 번에 보여 줌 |
| 다국어 | 한국어 안내 문구만 사용 |
| 완료 시각 기록 | 완료 여부만 기록 |
| 화면 자체의 구현 | 이 저장소는 서버만 다룸. 화면 문구는 참고용 |

## 6. 성공 기준
- `REQUIREMENTS.md`의 모든 수용 기준이 자동 테스트로 확인된다.
- 와이어프레임의 모든 화면과 상태가 서버 동작만으로 채워질 수 있다.

## 7. 가정
- 시간 기준은 한국 시간이다.
- 요일 표시, 날짜 모양 같은 보여 주는 방식은 화면이 정한다. 서버는 날짜 값만 다룬다.
- 삭제 전 "정말 삭제할까요?" 확인은 화면이 맡는다. 서버는 삭제 요청을 받으면 바로 지운다.
- 저장 후 목록으로 돌아가는 이동은 화면이 맡는다.
