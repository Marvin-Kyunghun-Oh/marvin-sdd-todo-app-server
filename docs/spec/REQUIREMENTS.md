## 용어
| 용어 | 뜻 |
| --- | --- |
| 할 일 | 제목, 설명, 마감일, 완료 여부를 가진 항목 하나 |
| 진행 중 | 완료되지 않은 상태 |
| 완료 | 끝났다고 표시된 상태 |
| 오늘 | 한국 시간 기준의 오늘 날짜 (D-10) |
| 기한 지남 | 완료되지 않았고, 마감일이 오늘보다 이전인 상태 |

## 입력 규칙
| 항목 | 규칙 |
| --- | --- |
| 제목 | 필수. 앞뒤 공백을 제거한 뒤 1자 이상 100자 이하 (D-01, D-03) |
| 설명 | 선택. 앞뒤 공백을 제거한 뒤 1,000자 이하. 제거 후 비어 있으면 설명 없음으로 본다 (D-02, D-27) |
| 마감일 | 선택. 날짜 하나 (시각 없음) |
| 완료 여부 | 완료 또는 진행 중. 새 할 일은 진행 중 |

글자 수는 한글, 영문, 숫자, 공백, 이모지 모두 1자로 센다 (D-28).

## 기능 요구사항

### FR-01 할 일 추가
새 할 일은 제목만으로 추가한다. 마감일과 설명은 추가 후 수정에서 넣는다 (D-06).
- **AC-01-1**
  - Given 할 일이 하나도 없을 때
  - When 제목 "장보기"로 추가하면
  - Then 제목 "장보기", 설명 없음, 마감일 없음, 진행 중인 할 일이 새로 만들어진다.
- **AC-01-2**
  - Given 같은 제목의 할 일이 이미 있을 때
  - When 같은 제목으로 추가하면
  - Then 새 할 일이 별도로 만들어진다 (D-05).
- **AC-01-3**
  - Given 제목 앞뒤에 공백이 있을 때
  - When 추가하면
  - Then 공백이 제거된 제목으로 저장된다 (D-03).

### FR-02 제목 검사
제목이 비어 있거나 너무 길면 추가와 수정을 거부하고 이유를 알려 준다.
- **AC-02-1**
  - Given 제목이 비어 있을 때
  - When 추가하면
  - Then 할 일은 만들어지지 않고 "제목을 입력해 주세요."라는 안내가 돌아온다.
- **AC-02-2**
  - Given 제목이 공백 문자로만 이루어져 있을 때
  - When 추가하면
  - Then 비어 있는 경우와 똑같이 거부된다 (D-03).
- **AC-02-3**
  - Given 제목이 101자일 때
  - When 추가하면
  - Then 할 일은 만들어지지 않고 "제목은 100자 이하로 입력해 주세요."라는 안내가 돌아온다 (D-01).
- **AC-02-4**
  - Given 제목이 정확히 100자일 때
  - When 추가하면
  - Then 정상적으로 만들어진다.
- **AC-02-5**
  - Given 기존 할 일이 있을 때
  - When 제목을 비우거나 공백만 넣어 수정하면
  - Then 수정은 거부되고 "제목을 입력해 주세요."라는 안내가 돌아오며 기존 내용은 그대로다 (D-04).
- **AC-02-6**
  - Given 설명이 1,001자일 때
  - When 추가 또는 수정하면
  - Then 거부되고 "설명은 1,000자 이하로 입력해 주세요."라는 안내가 돌아온다 (D-02).

### FR-03 목록 보기
모든 할 일을 등록한 순서대로 돌려준다. 먼저 등록한 것이 위, 새 항목이 아래다 (D-11).
- **AC-03-1**
  - Given 할 일 "가", "나", "다"가 이 순서로 등록되어 있을 때
  - When 목록을 보면
  - Then "가", "나", "다" 순서로 돌아온다.
- **AC-03-2**
  - Given 마감일이나 완료 여부가 서로 다른 할 일들이 있을 때
  - When 목록을 보면
  - Then 마감일이나 완료 여부와 관계없이 등록한 순서를 유지한다.
- **AC-03-3**
  - Given 각 할 일에 대해
  - When 목록을 보면
  - Then 제목, 설명, 마감일, 완료 여부, 기한 지남 여부가 함께 돌아온다.

### FR-04 상태별 보기
전체, 진행 중, 완료 중 하나를 골라 목록을 볼 수 있다. 고르지 않으면 전체다.
- **AC-04-1**
  - Given 진행 중 3개, 완료 1개가 있을 때
  - When 진행 중만 보면
  - Then 진행 중 3개만 등록 순서대로 돌아온다.
- **AC-04-2**
  - Given 같은 상황에서
  - When 완료만 보면
  - Then 완료 1개만 돌아온다.
- **AC-04-3**
  - Given 같은 상황에서
  - When 전체를 보면
  - Then 4개가 모두 돌아온다.
- **AC-04-4**
  - Given 완료된 할 일이 하나도 없을 때
  - When 완료만 보면
  - Then 오류 없이 빈 목록이 돌아온다. (보여 줄 문구는 화면이 맡는다 — D-24)
- **AC-04-5**
  - Given 할 일이 있을 때
  - When 전체, 진행 중, 완료 외의 보기 구분으로 목록을 요청하면
  - Then 거부되고 "보기 구분이 올바르지 않아요. 전체, 진행 중, 완료 중에서 골라 주세요."라는 안내가 돌아온다 (D-30).

### FR-05 개수 요약
전체, 진행 중, 완료 개수와 "남은 개수"를 돌려준다. 남은 개수는 보기 선택과 관계없이 전체 중 진행 중인 개수다 (D-12).
- **AC-05-1**
  - Given 진행 중 3개, 완료 1개가 있을 때
  - When 요약을 보면
  - Then 전체 4, 진행 중 3, 완료 1, 남은 개수 3이 돌아온다.
- **AC-05-2**
  - Given 같은 상황에서
  - When 완료만 보면서 요약을 함께 받으면
  - Then 요약 값은 위와 같고, 보기 선택에 영향을 받지 않는다.
- **AC-05-3**
  - Given 할 일이 하나도 없을 때
  - When 요약을 보면
  - Then 전체 0, 진행 중 0, 완료 0, 남은 개수 0이 돌아온다.

### FR-06 완료 표시와 되돌리기
할 일을 완료로 표시하거나 진행 중으로 되돌릴 수 있다 (D-14).
- **AC-06-1**
  - Given 진행 중인 할 일이 있을 때
  - When 완료로 표시하면
  - Then 그 할 일은 완료가 되고 요약의 진행 중은 1 줄고 완료는 1 는다.
- **AC-06-2**
  - Given 완료된 할 일이 있을 때
  - When 진행 중으로 되돌리면
  - Then 그 할 일은 진행 중이 되고 요약이 그에 맞게 바뀐다.
- **AC-06-3**
  - Given 이미 완료된 할 일에
  - When 다시 완료로 표시하면
  - Then 오류 없이 완료 상태가 유지된다.
- **AC-06-4**
  - Given 이미 진행 중인 할 일에
  - When 다시 진행 중으로 되돌리면
  - Then 오류 없이 진행 중 상태가 유지된다 (D-29).
- **AC-06-5**
  - Given 할 일이 있을 때
  - When 완료 여부 없이 완료 표시를 요청하면
  - Then 거부되고 "요청 내용을 읽을 수 없어요. 입력한 내용을 확인해 주세요."라는 안내가 돌아오며 할 일은 바뀌지 않는다 (D-32).

### FR-07 할 일 한 건 보기
특정 할 일을 지정해 그 전체 내용을 볼 수 있다 (D-26).
- **AC-07-1**
  - Given 할 일이 있을 때
  - When 그 할 일을 열면
  - Then 제목, 설명, 마감일, 완료 여부, 기한 지남 여부가 돌아온다.

### FR-08 할 일 수정
제목, 설명, 마감일, 완료 여부를 수정할 수 있다. 저장하면 수정 내용이 바로 반영된다.
- **AC-08-1**
  - Given 제목 "PRD 초안", 마감일 없음인 할 일이 있을 때
  - When 제목을 "PRD 초안 작성하기", 설명을 "목적과 범위 정리", 마감일을 2026-11-12로 저장하면
  - Then 세 값이 모두 반영되어 돌아온다.
- **AC-08-2**
  - Given 진행 중인 할 일이 있을 때
  - When 수정에서 완료로 표시하여 저장하면
  - Then 완료 상태가 된다.
- **AC-08-3**
  - Given 수정 내용이 규칙에 어긋날 때 (FR-02)
  - When 저장하면
  - Then 거부되고 기존 내용은 하나도 바뀌지 않는다.
- **AC-08-5**
  - Given 설명이 "목적과 범위 정리"인 할 일이 있을 때
  - When 설명을 비워서 저장하면
  - Then 설명 없음이 된다 (D-27).
- **AC-08-6**
  - Given 설명이 없는 할 일이 있을 때
  - When 설명을 공백 문자로만 채워 저장하면
  - Then 설명 없음으로 저장된다 (D-27).
- **AC-08-7**
  - Given 할 일이 있을 때
  - When 완료 여부 없이 수정을 저장하면
  - Then 거부되고 "요청 내용을 읽을 수 없어요. 입력한 내용을 확인해 주세요."라는 안내가 돌아오며 기존 내용은 그대로다 (D-32).

### FR-09 마감일 지정과 삭제
마감일은 지정, 변경, 삭제할 수 있다. 마감일이 없는 할 일도 허용하고 (D-07), 오늘보다 이전 날짜도 마감일로 지정할 수 있다 (D-25).
- **AC-09-1**
  - Given 마감일이 없는 할 일이 있을 때
  - When 마감일 2026-11-12를 지정하면
  - Then 마감일이 2026-11-12로 저장된다.
- **AC-09-2**
  - Given 마감일이 있는 할 일이 있을 때
  - When 마감일을 지우면
  - Then 마감일 없음 상태가 되고, 기한 지남이 아니다.
- **AC-09-3**
  - Given 마감일이 없는 할 일이 있을 때
  - When 목록을 보면
  - Then 마감일 없음으로 돌아온다 (마감 문구 생략은 화면이 맡는다).
- **AC-09-4**
  - Given 날짜가 아닌 값을 마감일로 보낼 때
  - When 저장하면
  - Then 거부되고 "마감일을 올바른 날짜로 입력해 주세요."라는 안내가 돌아온다. 문자열이 아닌 값(숫자, true 등)도 날짜가 아닌 값으로 본다 (D-36).
- **AC-09-5**
  - Given 오늘이 2026-11-10일 때
  - When 마감일을 2026-11-01로 지정하면
  - Then 저장되고 기한 지남이다 (D-25).

### FR-10 기한 지남 판정
기한 지남은 서버가 계산한다. 조건은 (1) 진행 중이고 (2) 마감일이 있고 (3) 마감일이 오늘보다 이전이다 (D-08, D-09, D-10).
- **AC-10-1**
  - Given 오늘이 2026-11-10이고, 진행 중이며 마감일이 2026-11-06인 할 일이 있을 때
  - When 목록을 보면
  - Then 그 할 일은 기한 지남이다.
- **AC-10-2**
  - Given 오늘이 2026-11-10이고, 진행 중이며 마감일이 2026-11-10인 할 일이 있을 때
  - When 목록을 보면
  - Then 기한 지남이 아니다 (마감 당일은 지남이 아님).
- **AC-10-3**
  - Given 오늘이 2026-11-10이고, 진행 중이며 마감일이 2026-11-12인 할 일이 있을 때
  - When 목록을 보면
  - Then 기한 지남이 아니다.
- **AC-10-4**
  - Given 오늘이 2026-11-10이고, 완료되었으며 마감일이 2026-11-09인 할 일이 있을 때
  - When 목록을 보면
  - Then 기한 지남이 아니다 (완료된 항목은 표시하지 않음).
- **AC-10-5**
  - Given 기한 지남이던 할 일이 있을 때
  - When 완료로 표시하면
  - Then 기한 지남이 해제된다.
- **AC-10-6**
  - Given 한국 시간으로 2026-11-10 00:30(세계 표준시로는 11-09)일 때
  - When 마감일 2026-11-09인 진행 중 할 일의 기한 지남을 판정하면
  - Then 오늘은 2026-11-10으로 계산되어 기한 지남이다.

### FR-11 할 일 삭제
할 일을 삭제한다. 삭제된 할 일은 복구할 수 없다 (D-15).
- **AC-11-1**
  - Given 할 일이 있을 때
  - When 삭제하면
  - Then 그 할 일은 이후 목록과 요약에서 사라진다.
- **AC-11-2**
  - Given 방금 삭제한 할 일을 가리킬 때
  - When 다시 열면
  - Then "할 일을 찾을 수 없어요. 이미 삭제되었을 수 있어요."라는 안내가 돌아온다 (FR-12).

### FR-12 없는 할 일 처리
존재하지 않거나 이미 삭제된 할 일에 대한 보기, 수정, 완료 표시, 삭제는 모두 같은 방식으로 실패한다.
- **AC-12-1**
  - Given 한 번도 만들어진 적 없는 할 일을 가리킬 때
  - When 열면
  - Then "할 일을 찾을 수 없어요. 이미 삭제되었을 수 있어요."라는 안내가 돌아온다.
- **AC-12-2**
  - Given 한 번도 만들어진 적 없는 할 일을 가리킬 때
  - When 수정, 완료 표시, 삭제를 시도하면
  - Then 각각 같은 안내가 돌아오고, 다른 할 일은 바뀌지 않는다.
- **AC-12-3**
  - Given 번호로 읽을 수 없는 값(예: "abc", 0, 음수)으로 할 일을 가리킬 때
  - When 열기, 수정, 완료 표시, 삭제를 시도하면
  - Then 존재하지 않는 할 일과 같은 안내("할 일을 찾을 수 없어요. 이미 삭제되었을 수 있어요.")가 돌아온다 (D-33).

### FR-13 빈 목록
할 일이 하나도 없을 때도 정상으로 취급한다.
- **AC-13-1**
  - Given 할 일이 하나도 없을 때
  - When 목록을 보면
  - Then 오류 없이 빈 목록과 모든 개수 0이 돌아온다. ("아직 할 일이 없어요" 문구는 화면이 맡는다 — D-24)

### FR-14 일관된 안내
모든 거부와 실패는 같은 모양의 안내로 돌아온다. 안내에는 무엇이 문제인지 알려 주는 문장이 들어 있다. 입력 규칙에 정한 앞뒤 공백 제거 외에는 서버가 입력한 내용을 바꾸지 않으며, 거부된 입력으로 저장된 값이 생기지 않는다.
- **AC-14-1**
  - Given 서로 다른 이유(제목 없음, 너무 긴 제목, 없는 할 일)로 실패했을 때
  - When 안내를 비교하면
  - Then 모두 같은 구성(실패 종류, 사람이 읽을 문장)을 가진다.
- **AC-14-2**
  - Given 추가가 거부되었을 때
  - When 목록과 요약을 다시 보면
  - Then 개수와 내용이 거부 이전과 같다.
- **AC-14-3**
  - Given 요청 내용을 읽을 수 없을 때 (깨진 형식, 값의 종류가 맞지 않음, 지원하지 않는 Content-Type/Accept 등 — D-37)
  - When 추가, 수정, 완료 표시를 요청하면
  - Then 거부되고 "요청 내용을 읽을 수 없어요. 입력한 내용을 확인해 주세요."라는 안내가 돌아오며 저장된 내용은 바뀌지 않는다 (D-31).
- **AC-14-4**
  - Given 서버 내부에서 예상하지 못한 오류가 났을 때
  - When 어떤 요청이든 처리하면
  - Then "서버에 문제가 생겼어요. 잠시 후 다시 시도해 주세요."라는 안내가 같은 구성으로 돌아오고, 내부 정보는 담기지 않는다 (D-34).
- **AC-14-5**
  - Given 서버가 제공하지 않는 주소로 요청할 때
  - When 처리하면
  - Then "요청한 주소를 찾을 수 없어요."라는 안내가 같은 구성으로 돌아온다 (D-35).
- **AC-14-6**
  - Given 서버가 제공하는 주소에 허용되지 않는 요청 방식으로 요청할 때
  - When 처리하면
  - Then "지원하지 않는 요청 방식이에요."라는 안내가 같은 구성으로 돌아온다 (D-35).

## 실패 안내 문구 (확정)
테스트는 아래 문장을 정확히 검사한다 (D-24).

| 상황 | 문구 |
| --- | --- |
| 제목 없음 | 제목을 입력해 주세요. |
| 제목이 너무 김 | 제목은 100자 이하로 입력해 주세요. |
| 설명이 너무 김 | 설명은 1,000자 이하로 입력해 주세요. |
| 마감일이 날짜가 아님 | 마감일을 올바른 날짜로 입력해 주세요. |
| 없는 할 일 | 할 일을 찾을 수 없어요. 이미 삭제되었을 수 있어요. |
| 보기 구분이 올바르지 않음 | 보기 구분이 올바르지 않아요. 전체, 진행 중, 완료 중에서 골라 주세요. |
| 요청 내용을 읽을 수 없음 | 요청 내용을 읽을 수 없어요. 입력한 내용을 확인해 주세요. |
| 서버 내부 오류 | 서버에 문제가 생겼어요. 잠시 후 다시 시도해 주세요. |
| 없는 주소 | 요청한 주소를 찾을 수 없어요. |
| 허용되지 않는 요청 방식 | 지원하지 않는 요청 방식이에요. |

실패가 아닌 상황(할 일이 하나도 없음, 보기 결과가 없음)은 서버가 빈 목록만 돌려주고, 보여 줄 문구는 화면이 맡는다.
